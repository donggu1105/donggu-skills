# 스타일 계약 (수치 정본)

실행 정본은 생성된 HTML의 `:root`이고, 이 문서는 그 값을 결정하는 계약이다.
**변경 규칙: 색 값과 폰트 패밀리만 프로젝트별 교체 가능. 역할 구조·타이포 스케일·모션 문법은 고정.**
HTML을 손으로 고쳐 값이 달라졌으면 이 문서(또는 덱 폴더 tokens.md)에 역기입한다 — 정본이 갈라지면 둘 다 못 믿는다.

## 모션 문법

| 장치 | 값 | 비고 |
|---|---|---|
| 입장 3종 | `.a` 페이드업 / `.aL` 좌측 진입 / `.aS` 스케일 팝 | `.slide.active` 스코프, `--d`로 지연 |
| 스태거 리듬 | 형제 간 0.1~0.2s 간격, 첫 요소 0.15~0.35s | `.mrow` 자식은 자동(0.45s부터 0.11s 간격) |
| 이동 점/카드 | 트랙 위를 단계별 **멈췄다 가는** infinite 주행 | `mkgo`·`dealgo` 참고, easing `cubic-bezier(.45,.05,.55,.95)` |
| 점선 흐름 | `ecg` 키프레임, dasharray 14 10 | ECG·합류 경로 공용 |
| 팝 강조 | `cubic-bezier(.2,.9,.3,1.2~1.25)` 오버슈트 | 슬램·정본 카드 |
| 펄스 | box-shadow 링 확산 2.4~2.6s | 질문·주인공 메뉴 |
| 금지 | 한 요소 두 애니메이션 규칙 / width·height 애니 / 입장 0.3s 미만 다발 | 컴파운드 또는 부모 래핑으로 해결 |

## 오버라이드 — 프로젝트별 교체

1. 덱 폴더에 `tokens.md`(이 문서와 같은 표 형식, 바꿀 값만)가 있으면 그 값으로 `:root`를 생성한다.
2. `DESIGN.md`(getdesign.md 등)가 있으면: YAML front matter의 `colors.*`를 위 역할에 매핑(대비·크로마 검증), 폰트 패밀리는 조건부 교체, typography 크기·motion은 **무시하고 계약 유지**, 컴포넌트·레이아웃 규칙은 부품 아이디어로만 채택.
3. 흡수 결과는 반드시 덱 폴더 `tokens.md`로 남긴다 — 파이프라인은 항상 `외부 md → tokens.md → :root`.

# LinkedIn Channel Reference

## 역할

전문성과 관점을 발견하게 하는 압축된 글이다. source의 사실을 근거로 하나의 판단을 선명하게 보여준다.

## 출력 계약

```text
본문 1개

수동 첫 댓글
<외부 링크가 있을 때 URL>
```

- 허용 분량: 800~1,400자. 기본 권장 범위는 1,200~1,400자다.
- 800~1,199자는 짧은 공지·후기처럼 압축이 장르에 맞을 때만 사용한다.
- 외부 URL은 본문에 넣지 않고 수동 첫 댓글로 분리한다. 자동 발행 경로가 댓글을 지원하지 않으면 URL을 누락하지 말고 수동 후속으로 표시한다.
- 해시태그는 기본 3~5개다. 사용자가 생략을 명시했을 때만 0개로 둔다.

## 문체

- 에세이·주장·오피니언: 평서체, 1인칭 `나/내`
- 행사 후기·공지·공감형: 정중한 존댓말, 1인칭 `저/제가`
- 한 글 안에서 두 톤을 섞지 않는다.
- 짧은 단문만 연달아 놓지 않고 중간 길이 문장으로 호흡을 만든다.

## 구조

1. 첫 3줄, 약 210자 안에서 질문·긴장·반전을 만든다.
2. 관찰한 사실이나 source의 핵심 장면을 제시한다.
3. 그 사실에서 나온 주장과 근거를 전개한다.
4. 기존 관행과 다른 점은 과장 없이 비교한다.
5. 지금의 자기 포지션이나 판단으로 닫는다.

## 후크

다음은 선택 가능한 유형이지 빈칸 템플릿이 아니다.

- 구체적 질문
- 약점이나 오해에 대한 고백
- 숫자와 실제 격차
- 현장 장면
- 통념과 반대되는 명제

후크가 본문의 결론을 과장하거나 source에 없는 사실을 만들면 안 된다.

## 앵글 모드

- 기본은 **채굴**: 현재 source에서만 나오는 서로 다른 앵글 3개를 내부적으로 만든 뒤, source 근거와 긴장이 가장 강한 하나만 골라 쓴다. 기존 결론·자기 인용으로 수렴하지 않는다.
- 사용자가 브랜드 관점 연결을 명시하면 **수렴**: 제공된 기존 관점과 의도적으로 연결할 수 있다.
- 모드를 묻는 질문 때문에 작성 흐름을 끊지 않는다. source가 명확하면 기본값을 적용한다.

## 마무리

- 평서체 에세이: 댓글 유도 질문보다 자기 포지션·판단으로 닫는다.
- 존댓말 후기·공감형: 글의 판단과 직접 연결된 질문 한 줄을 허용한다.
- “~라서.”, “~니까.” 같은 여운체 종결은 설명 문단에서 쓰지 않는다. 글 끝 자기 고백에서만 최대 한 번 허용한다.
- 아포리즘과 여운체를 한 문장에 겹치지 않는다.

## 금지

- 본문 외부 URL
- 본문 첫 줄의 습관적 장식 이모지
- 무관한 인물 멘션
- 깔끔한 3단 나열을 위한 사실 왜곡
- 모든 글을 FDE나 기존 브랜드 결론으로 연결
- 평서체 글 끝의 습관적 “여러분은 어떠세요?”

## 검수

- 첫 210자 안에 실제 긴장이 있는가.
- 800~1,400자 허용 범위이며, 1,200자 미만이면 짧게 쓸 장르상 이유가 있는가.
- 문단이 1~3문장으로 모바일에서 읽히는가.
- 본문 URL이 0개인가.
- 수동 첫 댓글 링크가 source와 정확히 일치하며 자동 발행에서 누락되지 않도록 표시됐는가.
- 해시태그가 기본 3~5개인가. 생략했다면 사용자의 명시 요청이 있었는가.
- 평서체와 존댓말이 섞이지 않았는가.
- 결말이 질문 공식이나 여운체 남용으로 끝나지 않는가.

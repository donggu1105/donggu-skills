# Threads Channel Reference

## 역할

한 가지 생각을 짧고 대화하듯 던져 답글을 여는 글이다. LinkedIn 문장을 잘라 붙이지 않는다.

## 출력 계약

```text
본문 1개
```

- 단일 게시물: 줄바꿈 포함 500자 이하
- 기본 호흡: 비어 있지 않은 5~7개 문단 또는 줄
- 본문 해시태그: 0개
- 외부 URL: 본문 금지. URL 없는 초안만 전달한다.
- 타래 5~7개: 사용자가 명시했을 때만 작성하고 수동 게시용으로 표시

## 문체

- 친근한 반말·평어
- 친구에게 생각을 설명하듯 쓴다.
- 정중한 LinkedIn 풀버전을 옮기지 않는다.
- 1인칭은 생략하거나 `나`를 쓴다. `저/제가`는 source 문맥상 필요할 때만 쓴다.

## 구조

1. 첫 문장은 가능하면 20자 안팎으로 가장 짧게 쓴다.
2. 다음 호흡에서 구체적 상황이나 관찰을 제시한다.
3. 한 가지 주장만 전개한다.
4. 기본은 독자가 자기 경험을 꺼낼 수 있는 구체적 질문으로 닫는다.

## 작성 규칙

- 단락당 1~2문장으로 쓴다.
- 모든 줄을 한 문장씩 기계적으로 끊지 않는다.
- `>` 인용 블록은 사용하지 않는다.
- “다음 ↓” 같은 체류 장치는 실제 후속 내용이 있을 때만 쓴다.
- 이모지는 내용상 필요한 경우 최대 1개만 쓴다.
- 선택지 A/B나 여러 버전을 함께 내지 않고 확정본 하나만 준다.
- 본문에는 해시태그를 붙이지 않고 자연어 키워드를 쓴다. 플랫폼 토픽 태그 선택은 발행 단계의 일이다.

## 답글 유도

- “어떻게 생각해?”처럼 글의 판단과 직접 연결된 질문을 기본으로 쓴다.
- 막연한 “여러분 생각은?”을 자동으로 붙이지 않는다.
- 사용자가 질문 없는 결말을 명시했을 때만 판단으로 닫는다.

## 검수

- 도구로 센 글자 수가 500자 이하인가.
- 비어 있지 않은 호흡이 5~7개인가.
- 주장 하나만 남았는가.
- 본문 URL이 0개인가.
- 본문 해시태그가 0개인가.
- LinkedIn 존댓말과 장문 호흡이 남지 않았는가.
